# Translator Workplace｜双模式译后编辑工作台

## 本次更新（V1.1）

- **终稿保护**：直接编辑“最终译文”后，其他审校决策不会悄悄覆盖手工文本。用户可以主动确认并重新生成终稿。决策撤销/恢复同时追踪手工编辑状态。
- **翻译方向**：可明确选择“中译英／英译中”，也可继续自动识别。
- **术语工具**：可新增、修改、删除术语，并导出 CSV。在线审校会将当前原文涉及的项目术语作为约束提示。术语来源由用户记录，平台不自动验证其权威性。
- **本地交付前 QA**：检查项目术语是否出现在译文、阿拉伯数字是否可能遗漏，以及尚未处理的决策。结果为提示，需要译员复核。
- **完整版本快照**：新版快照包含当时的全部项目工作数据（除快照列表本身），恢复前自动创建一份恢复点。仍兼容旧版快照。
- **更安全的 JSON 导入**：默认可以选择“追加项目”；如明确选择“覆盖”，先自动下载已有项目备份。
- **长文本比较**：常规使用逐词差异；超过计算阈值时，自动切换为句段级差异比较，避免直接报错。句段可能产生较大的修改块，仍需要人工核对。
- **批量 AI 理由**：按批次分析差异，无原先固定仅分析前 12 处的限制。较长原文会裁剪引用上下文，不可靠的原文定位不自动填写。
- **异步安全**：切换项目或模式后，忽略原项目仍在等待的 AI 返回结果。
- **TXT 导入**：原文和初译可以独立导入 UTF-8 TXT 文件。
- **界面**：缩小模式卡片，保留审校进度条和原有决策卡片。

## 双模式与保存

- **离线编辑**：支持通过浏览器打开网页后，在不调用 AI 的情况下处理文本。也可以直接下载并双击 \`index.html\` 进行本地编辑。通过 Vercel 网址首次访问网页仍需网络连接。
- **在线 AI 辅助**：请求会经由 Vercel 后端传送至 Agnes 模型。建议仅上传获得授权的文本。
- **存储位置**：当前项目仍保存在使用中的浏览器 \`localStorage\`，不同设备、浏览器或无痕窗口之间**不会自动同步**。请定期导出全部项目 JSON。
- **兼容旧数据**：继续读取此前 \`translator-workbench-agnes-cn-v3\` 格式的本地数据及 \`translator-workbench-agnes-cn-v2\` JSON 备份。
- **版本限制**：每项目至多 20 个快照。超过本地存储空间会触发保存失败提示，请导出备份。
- **手动终稿**：当终稿出现与决策自动拼接稿不同的手工编辑时，系统保留手动文本；需要重新同步时必须主动确认。

## 部署到 Vercel

此仓库的应用位于 \`译者决策工作台_公开双模式版/\` 目录。请在 Vercel Project Settings 中将 **Root Directory** 指向该目录，使用 Framework Preset **Other**，无需 Build Command。根目录内需要有 \`index.html\`、\`api/chat.js\`、\`api/health.js\` 和 \`vercel.json\`。

在 Vercel → Project Settings → Environment Variables 设置：

| 变量 | 用途 |
| --- | --- |
| \`AGNES_API_KEY\` | Agnes 平台申请的 API Key，仅在服务端使用 |
| \`CHAT_ENABLED\` | 设置为 \`true\` 时允许在线模型服务；\`false\` 为关闭 |
| \`SITE_ACCESS_CODE\`（可选） | 为在线 AI 接口设置访问码。建议向小范围受邀译员单独提供，切勿写入仓库 |

保存设置并 **Redeploy**，然后访问 \`https://你的域名/api/health\` 验证启用状态（\`ready: true\` 只表示基础配置就绪）。在页面“在线 AI”模式内点击“测试聊天连接”，才能确认模型真实可用。如果设置了 \`SITE_ACCESS_CODE\`，使用者在网页的访问码输入框填写后才可调用 AI。

**安全限制**：\`api/chat.js\` 具有请求大小上限、可选访问码及每分钟 24 次的*单实例、尽力而为*限流。Vercel Serverless 在多实例或实例重新启动的情况下，内存计数并不共享，因此**这不等于全局配额或抗滥用保证**。面向公众长期开放前仍应设置部署层的防滥用措施、持久化限流与额度监控。

\`\`\`

测试覆盖前端/后端脚本解析、元素 ID 重复与引用校验，以及中英文、标点和长文本差异重建。

## 尚待后续版本完成

当前仍属于以文本比较和人工决策为主的工作台。尚未完成严格的原文-译文句段自动对齐、CAT 格式（如 XLIFF/TMX）互操作、DOCX 格式保真、IndexedDB 大项目存储、跨设备同步，以及专业级语义 QA。不得将基础数字与术语检查视为完整的译文质量认证。
